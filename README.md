# AI对话复盘助手

一个浏览器扩展（Chrome / Edge 通用），自动记录你在 ai 聊天中的问答内容，支持搜索、导出和复盘。

## 它是什么

安装后，插件会在后台自动捕捉你与 ai 的每一轮对话（问题 + AI 回答），保存到浏览器本地，并通过侧边栏提供查看、搜索、复制、导出等功能。

## 为什么做

- 各类ai网页版平台的对话记录散落在不同的地方
- 没有「一键导出 / 本地存档」能力，重要的对话容易丢失。
- 有价值的提问与回答散落在一次次会话里，事后很难找回来。
- 想在本地整理、复盘自己的提问方式与 AI 的回答质量，缺少趁手的工具。

## 能解决什么问题

- **自动记录**：发消息后无需任何手动操作，对话自动存档。
- **本地保存**：数据存在浏览器本地（IndexedDB），不上传任何服务器，保护隐私。
- **随时检索**：按关键词搜索历史问题与回答。
- **导出复盘**：一键导出 Markdown 文件，方便整理与复盘。
- **会话归组**：按对话会话自动分组，保留上下文脉络。

## 快速开始

1. 打开 `edge://extensions`（或 `chrome://extensions`）。
2. 开启「开发人员模式」。
3. 点击「加载解压缩的扩展」，选择本项目目录。
4. 打开 [chat.deepseek.com](https://chat.deepseek.com) 正常聊天，点击工具栏图标打开侧边栏查看记录。

## 技术实现

- 通过主世界内容脚本包装 `fetch` / `XMLHttpRequest`，拦截 `https://chat.deepseek.com/api/v0/chat/completion` 接口。
- 解析流式响应（`text/event-stream`），提取用户问题与 AI 回答。
- 通过 `postMessage` 桥接到隔离世界脚本，再经 `chrome.runtime` 存入本地 IndexedDB。
- 侧边栏读取本地数据，提供搜索、复制、导出、清空等能力。
